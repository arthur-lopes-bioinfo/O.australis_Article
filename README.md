## Overview

The study investigates whether genes acquired from bacteria by horizontal gene transfer (HGT), in particular enterotoxin-like genes, may be involved in the manipulation of ants by *Ophiocordyceps australis*. The analyses combine genome annotation, enterotoxin identification, comparative genomics, transcriptomics, HGT detection, transposable element analysis and molecular dynamics simulations of two candidate toxins (OaHLEα16 and OaHLEα19) bound to an octopamine receptor.

## Molecular dynamics (steps 13 and 14)

Each system (OaHLEα16 and OaHLEα19 in complex with the octopamine receptor) follows the same pipeline, submitted through SLURM:

`minim.sh` → `equil.sh` → `prod.sh` (chained by `submit_all.sh`), followed by post-MD plotting (`plot_postMD_*.py`).

Key parameters: 309.65 K, v-rescale thermostat, C-rescale barostat (production), PME electrostatics, 2 fs time step, 100,000,000 steps (200 ns) of production.

**Before running:**

- The scripts assume a SLURM cluster with GPU and a `gromacs` node constraint. Adapt the `#SBATCH` directives to your environment.
- The environment setup block (`conda activate gmx2023` / `source /usr/local/gromacs/bin/GMXRC`) uses paths specific to the authors' cluster. Change it to your GROMACS installation.
- Required input files (`step3_input.gro`, `topol.top`, `index.ndx`) are **not** generated by these scripts. [Add how they were generated and the force field used.]
- Post-MD plotting expects `.xvg` files (H-bonds, RMSD, Rg, RMSF for complex, receptor and toxin) in `postMD_<system>/data/`. The receptor length is set by `--receptor-residues` (default: 545).

Post-MD plotting example:

```bash
python plot_postMD_OaHLEa16.py --data-dir postMD_OaHLEa16/data --output-dir postMD_OaHLEa16/figures
```

Outputs are saved as PNG, TIFF and SVG (300 dpi, Okabe-Ito colorblind-friendly palette).
